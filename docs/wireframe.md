# 프로젝트 wireframe

## 목적
### 개발 부분 
 - react를 이용한 프론트엔드 완전 정복
 - react와 활용도 및 사용도가 높은 라이브러리 및 기능들을 접목해서 개발
 - 지속적으로 기능 추가 및 서비스 확장이 용이한 서비스를 구축한다.

###  서비스 부분
 - 공공 날씨 API를 사용해서 지금 위치한 현재 날씨를 보여준다.
 - 원하는 나라를 선택해서 해당하는 환율과 변동 사항을 표시한다. (ex. 트래블월렛)
 - 자주 보는 웹 페이지를 리스트업하고 이동할 수 있도록 보여준다.
 - 일부 페이지들은 개발 학습용 페이지들로 그리도 타입으로 한번에 보여주고, 클릭하여 개발 결과 페이지로 이동한다.



## 기획
0. 사용 환경
   - 모바일, PC 모두 사용 가능

   - 표시할 기본 그리드
     - 현재 위치 기준 날씨 표시
     - 설정한 환율 정보
     - 즐겨찾는 사이트 리스트

# wireframe 2

## 서비스명 - MineMine


## 서비스 정의
- 해당 서비스는 개인적인 필요 정보들을 한눈에 모아보는 개인용 서비스로 외부 공공 API나 MCP를 이용해서 데이터들을 조회하여 보여준다.
- 보여주는 내용들의 주제들 또한 장르 불분하고 폭넓은 범위로 지속적인 커스텀을 통해 화면이 변할 수 있다.

### 화면 정의
0. 공통
- 공통 헤더
  - left : 서비스명 로고
  - right : 화면라이트모드/다크모드 설정 토글, 홈 버튼, 설정 버튼

1. 메인 화면
- 장르별 표시할 내용들은 모두 컴포넌트로 분리되어있으며 사용자가 컴포넌트 목록들을 조회하고 선택하여 메인 화면에 커스텀 하여 보여준다. 
- 대시보드와 같은 그리드 형식으로 표시한다. (아이폰의 위젯 기능과 유사한 UI 구조를 따른다.)

2. 컴포넌트
- 컴포넌트의 대부분은 외부 공공/오픈 API 나 MCP를 사용한 각각의 컴포넌트이며 대부분 조회 전용이다.
    - 오늘의 날씨 표시
    - 오늘의 환율 표시 (달러, 엔화)
    - IT 뉴스
    - 경제 뉴스
    - 현재 일자에 해당하는 달력 표시 (월간 달력)
   
3. 설정 화면
- 컴포넌트들의 목록을 조회하고 표시한다. 메인에 표시할 컴포넌트는 최소 2개에서 최대 10개까지 선택할 수 있어야 한다. 
- 설정 화면 가장 하단에 서비스 버전정보를 작게 표시한다. v0.0.1 이후 업데이트 사항에 맞춰 버전정보를 바꾸고 표시한다. 커밋마다 버전업 하지 않고 커밋 명령과 버전 업데이트 명령을 같이 할 때 버전 정보를 업데이트 처리한다. (예. 커밋해줘 / 버전 업데이트해서 커밋해줘)
- 설정 화면 최하단에 특정 텍스트 워딩을 넣고 클릭하면 사용하는 api, mcp 출저들을 확인 할 수 있는 별도의 페이지를 열어서 보고 닫을 수 있다.
  (특정 텍스트 워딩은 해당 목적에 맞는 문구로 정해서 적용해줘.)
